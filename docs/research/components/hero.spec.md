# Hero specification

- Target: `src/components/Hero.tsx`
- Interaction model: time + pointer + scroll driven.
- Full viewport, cream `#f4f4ed`, dark olive text, contour-line background.
- Identity copy uses very large compressed uppercase type.
- Central original 16-bit platform-game avatar replaces the reference portrait.
- Hover changes the avatar into AI mode with a neural-network halo, data cubes, and circuit-trace jacket; no laboratory coat.
- Entrance: avatar rises and scales into place. Scroll: copy and avatar move at different rates.
- Mobile: compact title above the avatar occupying the lower viewport.
