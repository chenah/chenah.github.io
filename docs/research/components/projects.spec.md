# Projects specification

- Target: `src/components/Projects.tsx`
- Interaction model: scroll reveal + hover.
- Cream background, two asymmetric case-study panels.
- Each card includes a paper-like screenshot preview built from the corresponding publication: venue header, paper title, and a custom figure for audio moderation, AI-role networks, avatar attention, or LLM coding.
- Hover tilts/scales the paper and inverts the arrow chip.
- Mobile: one-column cards.
