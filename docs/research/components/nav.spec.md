# Nav specification

- Target: `src/components/Nav.tsx`
- Interaction model: click + scroll-spy.
- Fixed at the viewport top; transparent, no full-width bar.
- Cream/olive logo lockup at left, lime language button and square menu control at right.
- Desktop exposes section links; mobile opens a full-width olive panel.
- Hover: lime fill or 2px underline, 220ms ease.
- Responsive: desktop links hidden below 768px.
